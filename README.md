# NASA New Tab

A custom, space-themed new tab page built for the [Hack Club Stardance: Give Your Website a Pulse](https://stardance.hackclub.com/missions/nasa-page) mission.

## About The Project
This project transforms your default new tab into an aesthetic, highly functional space dashboard. It fulfills all the requirements for the "Give Your Website a Pulse" mission, including a custom UI (no templates), a deployed website, API integrations, and local data storage.

## Features
- **Dynamic Backgrounds**: Fetches the NASA Astronomy Picture of the Day (APOD) daily and sets it as the stunning background of your new tab page.
- **Live Clock & Greeting**: Displays the current time and a contextual greeting based on the time of day.
- **Quick Links**: Save your favorite bookmarks using `localStorage` for quick access. Includes a sleek modal for adding new links.
- **Search**: Built-in Google search bar with smooth glassmorphism styling.
- **Info Modal**: Click on the NASA info in the top left to read the description of the day's image.

## Tech Stack
- **HTML5**: Semantic structure.
- **CSS3**: Glassmorphism, CSS Variables, Flexbox, smooth transitions and keyframe animations.
- **JavaScript (ES6+)**: Fetch API for NASA data, LocalStorage for persistence, DOM manipulation for the live clock and modals.

## Getting Started
1. Clone the repository: `git clone https://github.com/susantedit/Hack-club-stardance-Give-Your-Website-a-Pulse-.git`
2. Open `index.html` in your browser, or run a local server: `python -m http.server 8000`
