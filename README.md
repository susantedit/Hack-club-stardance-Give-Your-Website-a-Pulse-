## 🌟 COSMORA Key Features

- **Minimal New Tab Dashboard (HOME)**: Central digital clock (`10:46 AM`), Google search bar, and Bento Grid with daily astronomy news, customizable shortcuts hub, and interactive task checklist.
- **COSMORA Spacecraft Console (TODAY)**: Cinematic deep-space viewport featuring procedural starfield canvas, breathing nebula cloud, gas giant planet sphere, and 3D depth parallax.
- **Full 3D CSS Solar System (3D ORBITS)**: Full-bleed interactive 3D solar system with speed, size, and orbit scale controls.
- **Triple-State APOD Media Renderer**: Handles High-Res Images (with HD view links), YouTube 16:9 responsive embeds, native HTML5 MP4 videos, and interactive fallbacks.
- **Temporal Archive Explorer**: Search and view any historical NASA observation from **June 16, 1995 to Today** without full-page reloads.
- **Pure Browser Ambient Audio Synth**: Zero-dependency Web Audio API synthesizer generating atmospheric space drones.

## 🚀 Getting Started

### Local Development

1. **Clone the repository**:
   ```bash
   git clone https://github.com/susantedit/Hack-club-stardance-Give-Your-Website-a-Pulse-.git
   cd Hack-club-stardance-Give-Your-Website-a-Pulse-
   ```

2. **Install dependencies**:
   ```bash
   npm install
   ```

3. **Start the Dev Server**:
   ```bash
   npm run dev
   ```
   Open `http://localhost:5173` in your browser.

4. **Build for Production**:
   ```bash
   npm run build
   ```
